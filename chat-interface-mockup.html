Key Features

Natural Language

Users describe what they want in plain English. No need to know about style prompts, BPM, or structure tags.

Iterative Refinement

Users can ask for changes: "make it faster", "add a bridge", "change the mood". AI updates the song accordingly.

Quick Prompts

Suggested actions like "Make it faster", "Add a bridge", "Change to happy" help users who don't know what to ask.

Direct Editing

Users can edit the generated style and lyrics directly, then continue chatting for more refinements.

Context Awareness

AI remembers the conversation. "Make the chorus more energetic" knows which part to modify.

One-Click Generate

When happy with the style and lyrics, users click "Generate Song" to create the music.

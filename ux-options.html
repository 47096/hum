AI Lyrics & Style Generation

Three UX approaches for integrating MiniMax-M3 LLM to auto-generate lyrics and style prompts from a brief idea.

1
Sparkle per field
Recommended
Small AI icon next to each input. Click to generate content for that specific field independently.
Style prompt
Lyrics

Pros

  • Granular control per field
  • Can regenerate just one part
  • Familiar pattern (Notion, Docs)

Cons

  • Two separate actions
  • User needs to know what each field does
2
Single AI button
One button above the form. Opens a modal to describe the song idea, then fills both fields at once.
Style prompt
Lyrics

Pros

  • Simple, one action
  • Clear entry point
  • Good for beginners

Cons

  • Less control over individual fields
  • Modal adds friction
  • Can't regenerate just one part
3
Inline expand
Type a brief idea directly in the lyrics box. Click "Expand with AI" to generate full lyrics and style.
Style prompt
Lyrics

Pros

  • Natural flow
  • Keeps context in one place
  • Minimal UI changes

Cons

  • Confuses input purpose
  • User might not discover the feature
  • Overwrites what they typed
✨

Recommendation: Option 1 — Sparkle per field

This matches the pattern users already know from Notion, Google Docs, and other AI-powered tools. Each field stays independent — users can generate just the style, just the lyrics, or both. The sparkle icon is becoming a universal "AI assist" symbol. It's discoverable, non-destructive, and gives full control without adding modal friction.
